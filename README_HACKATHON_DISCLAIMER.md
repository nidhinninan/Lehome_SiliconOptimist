# Hackathon submission notice

This repository includes work related to a **hackathon submission** for the LeHome trial / challenge context.

## Branch layout

- **`main`** is the primary development line and may contain **commits and changes that go beyond** what was frozen or submitted for the hackathon. Treat **`main` as ahead of** the hackathon submission snapshot unless you are explicitly reviewing post-submission work.

- The **hackathon submission** itself is preserved on the **`principia_instance`** branch. For judging, reproducibility, or “what we actually submitted,” **check out and use `principia_instance`**, not necessarily `main`.

## Summary

| Branch               | Role |
|----------------------|------|
| `principia_instance` | Hackathon submission snapshot |
| `main`               | Ongoing work; may be ahead of the submission |

If anything in `main` disagrees with `principia_instance`, the branch named above is the reference for the submission unless organizers specify otherwise.
